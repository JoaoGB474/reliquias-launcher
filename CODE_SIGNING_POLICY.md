# Code signing policy

Free code signing provided by [SignPath.io](https://about.signpath.io), certificate by [SignPath Foundation](https://signpath.org).

## Team roles

- **Committers and reviewers:** [JoaoGB474](https://github.com/JoaoGB474)
- **Approvers:** [JoaoGB474](https://github.com/JoaoGB474)

Only release builds produced by this repository's GitHub Actions workflow from the public source code are signed. Every signing request is approved manually by an approver.

## Privacy

This program sends information to other networked systems only as described in the [privacy policy](PRIVACY.md): Discord sign-in, the Relíquias SMP server API, and file downloads from Mojang, NeoForge, Modrinth and GitHub. It has no telemetry or analytics.
